# Strongwiz

Strongwiz is a general-purpose, evidence-bounded reasoning laboratory.

Its purpose is to help a reasoning system choose useful distinctions, preserve
what experience has actually earned, investigate consequential surprises, and
revise the smallest sufficient part of its working model. ARC-AGI-3 is an
important development environment and adapter target, but it does not define
the project.

The implementation is being developed on a separate build branch so that this
initial public baseline remains an inspectable starting point.
