## Residuals and claim ceiling

Kevin Speak is experimental and disabled by default. Exact decompression and
cost accounting establish representation integrity, not unchanged or improved
model reasoning. No matched model-facing shorthand ablation has been run.

The streaming path covers ledger verification and run sealing. Evidence-capsule
packing and capsule verification remain materialized, so the end-to-end capsule
path is not yet claimed to be bounded-memory. The memory regression bounds row
count growth on its tested fixtures, not the size of one ledger row.

This build did not run ARC-AGI-3, observe `GameState.WIN`, use Hearthline, enter
a competition, submit anything, push this branch, publish a release, or establish
general intelligence. It prepares a model-neutral adaptive calibration surface
for a later separately authorized run.
