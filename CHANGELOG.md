# Changelog

All notable changes to Strongwiz will be recorded here. Dates use ISO 8601.

## [Unreleased]

### Added

- Initial model-neutral laboratory contracts for observations, actions,
  predictions, distinctions, proposals, control state, outcomes, and receipts.
- Content-addressed evidence storage and append-only hash-chained receipt
  support.
- Versioned accounts, derived facts, feedback state, local mechanic revision,
  subgoals, bounded path planning, experiment ablations, and runtime integrity
  manifests.
- Advisory A0BK-inspired routing guards with separate proposal and control
  planes.
- External task-grant and one-use permit machinery with PEA Core v1.1.3, PECAN
  v1.0.4, and SEED v0.3 review profiles.
- A bounded ARC-AGI-3 domain adapter as one example domain rather than project
  identity.
- Provenance, third-party boundary, contribution, security, and attribution
  documentation.

### Claim boundary

- This pre-alpha foundation makes no AGI, cross-domain performance,
  autonomous-contest, safety-certification, or independent-authority claim.

## [0.1.0-dev] - 2026-09-01

### Added

- Empty public baseline establishing the Strongwiz name, author/steward,
  workspace boundary, and CC BY 4.0 first-party license.
